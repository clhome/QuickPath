## 3. 对报告结论的两处事实修正（`事实优先`）

### 3.1 S-02 的「发布阻塞」定性偏高：声称的失败模式在 Win11 不可达
报告 §5 称 `CreateWindowExW` 的 `hinstance` 与注册时不配对「可能使类查找失败」，并在 §11 把它列为「稳定版前优先修复」。本轮实测（父 agent 独立复核）：把实例参数改回 `None` 后，10 个剪贴板用例**全部通过**（`GetLastError=0`、HWND 非空、`IsWindow=true`）——进程本地窗口类的查找不依赖 `CreateWindowExW` 的 `hinstance` 参数。

**结论**：S-02 不是可达缺陷，属「与 MSDN 写法不一致」的一致性/健壮性问题；修复保留（本身正确且无副作用），但**不应视为发布阻塞**。建议报告把 S-02 从「中风险 / 稳定版前修复」下调为「低 / 一致性」。

### 3.2 新增并已修复的回归：`with_state` 重入在 `panic = "abort"` 下会崩溃
R-05 重构（`bc9a2ba`）用 `RefCell::borrow_mut()` 替换 `&'static mut` 后，若在持有借用期间泵消息导致 WndProc 重入，会 panic；而 `[profile.release] panic = "abort"` + 访问器经 `extern "system" fn` 跨 FFI 调用 → **整个托盘程序直接退出**。这是重构引入的可用性回归，已在下一轮改为 `try_borrow_mut()` + 限频日志 + 降级为 `None`（`6b482fc`），并新增重入测试。
