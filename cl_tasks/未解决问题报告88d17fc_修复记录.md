## 2. U-01：显式前台单次触发（完整方案 A）

### 2.1 语义变更（关键）

`enable_totalcmd` / `enable_xyplorer` 从「启用后台自动探测」改为**「用户已授权该能力」**：

- 打开开关**不会**发起任何探测，也不会触碰剪贴板；
- TC / XYplorer **已彻底退出后台扫描**（`scanner` 不再有这两个来源）；
- 只有用户**手动触发一次**（托盘菜单 / 吸附条按钮）才会执行一次事务化探测。

### 2.2 落地结构

| 组件 | 位置 | 职责 |
|---|---|---|
| 授权开关 | `src/ui/settings.rs` 新增第 4 个 Tab「管理器联动 / Managers」 | 两个 Toggle 卡片 + 风险/用法提示卡；只写**草稿配置**，点“确定”才落盘 |
| 目标解析 | `src/managers/explicit_probe.rs`（新增） | 前台记录（有界时效）、目标解析、身份核验、授权闸门、结局枚举 |
| 单次探测 | `src/managers/totalcmd.rs` / `xyplorer.rs` 的 `probe_explicit_target()` | 只对**用户指定的那一个窗口**投递协议消息；投递前后复核身份；复用 `ClipboardTransaction` 全部 fail-closed 检查 |
| 触发入口 | `src/ui/tray.rs`（菜单项 1007/1008，未授权或无目标时置灰）+ `src/ui/floating_bar.rs`（顶栏 `[TC]`/`[XY]` 按钮） | 只在用户点击时调用 `crate::request_explicit_probe()` |

## 6. 诚实边界与偏差登记

1. **「目标管理器为前台」的落地口径**：触发入口本身会短暂持有前台（托盘菜单需要 `SetForegroundWindow` 才能正常弹出；悬浮条虽是 `WS_EX_NOACTIVATE`，但用户点击它时前台仍是文件对话框）。因此实现为：
   - 托盘菜单：在弹出菜单**之前**抓取当时的前台窗口并记入时效表；
   - 悬浮条：使用「最近曾处于前台」的记录（有效期 10 分钟）；
   - 两种路径都必须通过 `IsWindow` + `IsWindowVisible` + 顶层窗口 + 类名 + 进程镜像 + **PID 未变**的逐项复核，任一不一致即取消，且**投递前会再核一次**。
   这不是字面的“探测那一刻管理器仍是前台”，而是“用户发起触发那一刻的前台窗口 + 身份未变”。若审计要求字面语义，需要引入非剪贴板通道或要求用户先在管理器上按快捷键（见偏差 2）。
2. **未实现快捷键触发**：报告允许“用户点击或明确快捷键”，本轮只实现点击（托盘菜单 / 吸附条按钮）。快捷键会与现有呼出热键/系统热键冲突，未在本轮引入。
3. **能力变更**：TC / XYplorer 不再参与 AutoSwitch 与候选列表（这是移除后台探测的必然结果），已在 README 与手册中明确标注为“手动获取”。
4. **吸附条按钮的可见性**在 `show()` 时按当时配置决定；在吸附条已显示期间修改设置，需重新呼出才刷新（无功能影响）。
5. **`test_unauthorized_never_resolves_or_probes` 的 `probe_once(..., true)` 分支不在单测中执行**（会依赖真实前台窗口），其“无目标即零剪贴板触碰”由源码守卫（本模块不得出现 `ClipboardTransaction`）+ 投递前身份复核守卫共同保证。

## 7. 顺带发现并修复的问题（不在报告清单内）

1. **设置中心 Tab 几何不一致（真实 UI Bug）**：渲染用宽 118px，而 `handle_settings_mouse_move` 用 136px，导致第 2/3 个 Tab 的悬停高亮区域与实际渲染错位。已抽出 `TabGeometry` + `settings_tab_geometry()` / `settings_tab_left()` / `settings_tab_hit()`，渲染 / 悬停 / 点击三处共用，并新增 `test_settings_tab_geometry_and_hit_testing_are_consistent`。
2. **候选来源徽章误标**：`floating_bar::translate_source` 对未收录来源一律回退 `"Explorer"`，会把 Directory Opus 的候选标成资源管理器；改为回退到来源原名。
3. **死代码清理**：TC / XYplorer 的后台枚举扫描（`get_totalcmd_folders` / `get_xyplorer_folders` 及其 `*Folder` 结构、`scan_within` 的两个布尔参数、tracker 的两条过滤分支）随方案 A 一并删除，避免“授权即后台探测”的路径再次出现。
