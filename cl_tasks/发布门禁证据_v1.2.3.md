### 2.6 release workflow 打包与 SHA-256 清单 —— 发现并修复一处真实缺陷

**原实现（修复前）** `.github/workflows/release.yml`「整理打包产物与生成 SHA-256 清单」：

```powershell
Get-ChildItem -Path "dist" -File -Include "*.exe", "*.zip" | ForEach-Object { ... } | Out-File "dist/sha256sums.txt"
```

PowerShell 的 `-Include` **必须**配合带通配符的路径或 `-Recurse` 才生效。`-Path "dist"` 不含通配符、又未加 `-Recurse`，实测结果是**一个文件都匹配不到**，于是 `sha256sums.txt` 会**静默变成空清单** —— 而报告 §4.3 正是把这份清单当作「验证文件字节一致性」的兜底手段，空清单等于该兜底失效。

本机 5 组变体实测（`dist/` 内放置 3 个应打包产物 + 1 个故意放进去的杂散 `.txt`）：

| 变体 | 命令 | 命中数 |
|---|---|---|
| A | 修复前原样 `-Path "dist" -File -Include "*.exe","*.zip"` | **0** ❌ |
| B | 同上（相对路径，与 workflow 内一致） | **0** ❌ |
| C | `-Path "dist\*" -File -Include ...` | 3 ✅ |
| D | `-Path "dist" -File -Recurse -Include ...` | 3 ✅ |
| E | 不带 `-Include`，仅 `-File` | 4（把杂散文件也纳入）|

**修复**（提交 `d5793aa`）：改用 `-Path "dist\*"`，并新增 **fail-closed 守卫**——匹配结果为空时 `Write-Error` + `exit 1`，拒绝生成空清单：

```powershell
$artifacts = Get-ChildItem -Path "dist\*" -File -Include "*.exe", "*.zip"
if (-not $artifacts) {
    Write-Error "未能匹配到任何待校验产物（dist 为空或 -Include 未生效），拒绝生成空 SHA-256 清单"
    exit 1
}
$artifacts | ForEach-Object {
    $hash = (Get-FileHash -Path $_.FullName -Algorithm SHA256).Hash.ToLower()
    "$hash  $($_.Name)"
} | Out-File -FilePath "dist/sha256sums.txt" -Encoding ascii
```

**修复后本机等价复现**（同一含杂散文件的 `dist/`）：

```
命中数: 3

f23ad72951d3a7aad8e76c135cb5bbed36b7122371144675d92adb9490573fcf  QuickPath-v1.2.3-x64.exe
f23ad72951d3a7aad8e76c135cb5bbed36b7122371144675d92adb9490573fcf  QuickPath.exe
```
